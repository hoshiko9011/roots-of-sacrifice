# آزمون و پذیرش فعلی: ریشه‌های ایثار

این سند نتیجهٔ آزمون‌های اجراشده و شواهد محلی را از موارد اجرا نشده جدا می‌کند. مبنای بررسی، کد و تنظیمات فعلی Godot `4.7.2.stable.official.ed1daf0bf` است، نه طرح طراحی قدیمی.

## ۱. وضعیت‌ها و حدود شاهد

- `PASSED (خودکار)`: assertion متناظر در suite فعلی موفق شده است.
- `PASSED (ثابت)`: وجود یا نبود قابلیت از کد، preset یا manifest بررسی شده است؛ اجرای تعاملی تأیید نشده.
- `PASSED (تصویر)`: فقط رندر همان تصویر دسکتاپ در viewport پایه دیده شده است.
- `PASSED (بسته)`: فایل یا metadata داخل APK بررسی شده است.
- `PENDING`: آزمون لازم اجرا نشده و ابزار یا دستگاه در دسترس نبوده است.
- `BLOCKED`: اجرا به ابزار، دستگاه یا وابستگی مشخصی نیاز دارد که در محیط فعلی موجود نیست.

هر `PASSED` فقط به شاهد کنار خود مربوط است. باز شدن یک مودال در UI smoke، تأیید کامل چیدمان، کلیک همهٔ دکمه‌ها یا عملکرد Android نیست. انطباق با قوانین رسمی مسابقه بررسی نشده و ادعا نمی‌شود.

## ۲. فرمان و نتیجهٔ خودکار

فرمان تأییدشده:

```sh
./tools/Godot_v4.7.2-stable_win64_console.exe --headless --path . --scene res://tests/test_runner.tscn
```

نتیجه:

```text
Godot Engine v4.7.2.stable.official.ed1daf0bf
ROOTS_TESTS: 357 checks, 0 failures
```

ساختار تست فقط `tests/run_tests.gd` و `tests/test_runner.tscn` است. فایل‌های ذخیرهٔ این suite، `user://roots-test-save.json` و `user://roots-test-backup.json` و نیز فایل‌های UI smoke با پیشوند `user://roots-ui-test-` هستند و در پایان پاک می‌شوند؛ مسیر ذخیرهٔ واقعی بازی `user://garden.save` است. پیش از خروج نیز `AudioManager.shutdown()`، دو فریم انتظار و سپس ۰٫۱۵ ثانیه فرصت آزادسازی thread صدا اجرا می‌شود.

### ۲.۲. شکاف‌های صریح suite

- تکرار پاسخ درست، ورودی گزینهٔ نامعتبر و پاسخ نادرست برای همهٔ ۱۷ پرسش آزموده نشده‌اند.
- پاسخ اندیس‌های `1، 2، 3، 10، 11` در suite اجرا نمی‌شود؛ محتوای آن‌ها فقط از داده بررسی شده است.
- هر دو save خراب، تغییر اختصاصی checksum، نبود primary با backup معتبر، فایل tmp و شکست rename/write آزموده نشده‌اند؛ شکست کپی backup آزموده شده و save قبلی حفظ می‌شود.
- مرز ۲٬۰۰۰٬۰۰۰ بایت، همهٔ نوع‌ها و invariantهای semantic ذخیره آزموده نشده‌اند.
- پایداری تنظیمات با بازخوانی مستقل `ConfigFile` آزموده شده است، اما restart کامل برنامه و گوشی آزموده نشده‌اند؛ ماتریس کامل دستاوردها، امتیاز عددی نهایی و تمام کلیک‌های UI نیز `PENDING`اند.
- RTL روی دستگاه، لمس فیزیکی، Android Back، کارایی، نصب و رفتار واقعی airplane mode پوشش ندارند.
- تست علاوه بر API عمومی، `_read_save()` و `_valid_save()` را مستقیماً صدا می‌زند.
- log پایدار اجرای نهایی در `builds/test-results/automated-tests.log` ذخیره شد و گزارش‌های خام Android نیز در همان پوشه هستند.
